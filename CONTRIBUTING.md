# Contributing

Thanks for helping improve DevMind AI.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request:

```bash
npm run build
```

## Pull requests

Please keep changes focused and explain:

- what changed;
- why it changed;
- how it was tested;
- any security or provider-compatibility implications.

Never commit API keys, `.env` files, personal credentials, or provider secrets.
